# 暗影存档只读研究工具 v0.2

Python 3.10+，仅标准库、离线运行。读取原文件，不写回存档。本版本比 v0.1 多了公开样本校准的整体百分比候选、43 项地区分类计数候选、结构化 ID 前缀与溢出清单；仍不是已经游戏内验证的全收集查询器。

## 运行

退出游戏，使用稳定的存档副本。输出必须是全新的目录，不能与输入重叠。

```powershell
py -3 sottr_inspect.py --input "D:\SOTTR研究\存档副本" --output "D:\SOTTR研究\报告02" --catalog "data\collectible_id_candidates.json"
```

可重复 `--input`，`--max-pairs 0` 可关闭逐对二进制比较。省略 `--input` 时沿用 v0.1 的 Windows Documents 尝试发现；未在 Windows 实机验证。

## 新输出

- `report.json`：解压、哈希、差异、候选结构和解释
- `present_item_ids.csv` / `.json`：候选前缀和声明范围内 type28 区段的非零 ID；包括内部名称数组、原始伴随 DWORD、最低两位、记录位置、来源、许可证。没有字典时仍输出空清单，ID 字典扫描需传 `--catalog`
- `reference_presence_differences.csv` / `.json`：两个作者标注的 100% 参考存档共同拥有、当前活动记录中没有的 ID，仅限生存贮藏点、稀有资源贮藏点、独石、地下墓穴宝藏四组。不是通用未收集清单；状态、地区仍 unknown，完整来源和适用范围见 report.json
- `summary.txt`：中文摘要和整体百分比候选
- `research.log` / `invocation.json`：执行日志和复现参数

这些报告会含输入路径和存档内字符串，公开分享前请检查。

## 证据分层

1. `observed`：原始字节、哈希及解压结果
2. `candidate`：经样本比对得到的结构假说或异常值
3. `community_correlated`：公开作者标注存档、路线说明或社区 ASL 计数与磁盘观察相互支持
4. 原有 `validated` 数据模型：本研究未向其填入已知进度或收藏状态；`SaveSlot.overall_completion_percent` 等仍为 null，物品状态仍为 unknown

`community_correlated` 刻意放在独立 `derived_candidates` 层，不能作为已验证模型的输入。地区源目标来自社区脚本，未证明适用所有版本/DLC。若计数超出源目标，保留原始值，但候选计数和候选剩余数置 null。没有计算地区百分比，也没有从全字典减去当前 IDs 制作“未收集清单”。

ID 存在只说明在候选记录中出现。原始伴随值可以是大整数，最低两位 1/3 不被解释成已收集/未收集。ID 为零才被视为空 ID 槽；其伴随字及最低两位允许任意值。旧镜像块可能落后，不使用镜像拒绝输入，也不作为当前物品列表来源。

## 格式范围

候选解释仅在 4 MiB 解压样本家族且候选主区段流完整走到声明结尾时启用。主流字节长度在 0xBFD0，开始于 0xBFD4；每段 DWORD 的低 8 位是候选类型，高 24 位是包含头的 DWORD 数。每段必须非零且不越界，最多 50,000 段。

前缀从 0x44 起有 512 个 8 字节槽；可部分填满。可选 type28/0x1C 区段大小 4112 字节：16 字节头后有 512 个 8 字节候选溢出槽。只扫描声明主流内的这些区段，忽略流结束后可能残留的旧内容。零 ID 不输出；未知非零 ID 保留而不伪造名称。

地区候选行基址 0x10BC，步长 104 字节，映射事实在 `data/region_counter_candidates.json`。本结构通过现有私人及公开样本支持，不是通用文件签名。`profile.dat` 不参加候选进度解释。CLI 仅发现 profile.dat 和 save数字.dat；挑战古墓专用文件不自动作为普通槽位分析。

## 安全与边界

沿用 v0.1：zlib 从偏移 0 开始，校验和与 EOF 必须有效；压缩和解压各最多 64 MiB；最多 128 文件/64 对；输入符号链接忽略；输出新目录独占创建，不能覆盖或与输入父子重叠；读取前后完整 SHA-256 相同才生成报告。单次比较、字符串和目录扫描有数量上限。尾随压缩数据不作为正文静默合并。

退出码：0 全部可解压；2 已生成报告但有解压失败；1 路径/资源/输入变化错误。Python 标准库不能完全锁住恶意并发替换的路径，应使用稳定副本。

## 测试

```text
python -m unittest discover -s tests -v
```

可选真实测试：设置 `SOTTR_SAMPLE_DIR` 到本次原始五文件目录，设置 `SOTTR_PUBLIC_DIR` 到按原 ZIP 名称解压的公开样本父目录。参考命令与结果在 `test_results.txt`、`run_results.txt`。公开存档二进制不随工具分发，下载来源与哈希在 `evidence/public_sources.json`。

29 项测试覆盖旧版安全测试、原始五文件、20 个公开普通存档、可选溢出、部分前缀、伴随字高位、空 ID 残留值、流边界、零长度、过大长度、无穷/NaN、越界地区计数、声明流外旧段排除。真实样本测试是可选项，缺少环境变量会明确跳过。
