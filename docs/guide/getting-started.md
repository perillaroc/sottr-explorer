# 快速开始

## 准备

- Windows 10 / 11；
- Steam 版《古墓丽影：暗影》（含 Definitive Edition）；
- 建议先退出游戏，或至少不在游戏写入存档的同时分析——应用会读取稳定快照，
  但退出游戏能让“稳定”更容易成立。

## 第一次分析

1. 启动应用。
2. 选择存档：应用默认扫描 `文档\Shadow of the Tomb Raider\*.dat`，也可以手动挑选文件。
3. 等待分析完成。分析期间可以取消；取消不会产生成功报告。
4. 在左侧切换「概览」「全收集」「区域与收集」，或打开「地图查询」。
5. 点任意条目查看详情：获取方式、外部攻略链接、同一子关卡内的相对位置。

## 关于存档文件

- `profile.dat` 会被识别为资料文件，只做容器观察，不参与战役进度判断。
- 应用不会替你挑选、删除或改写存档；槽位与账户分组只是展示方式。
- 如果正在游戏内并发生写入，刷新可能失败；应用会保留上一次快照并明确标记为过期。
