# 位置与地图

## 位置是“关卡内相对位置”

图鉴里的坐标不是世界坐标，也不是导航路线。每个子关卡有自己独立的归一化空间：

- `position.x` / `position.y` 取值 `[0, 1]`；
- 原点在底图取景框西北角，**y 向下（向南）增大**；
- 不同子关卡的 `[0,1]` 空间互不相通，**不存在全局地图坐标**。

投影到图片时是纯比例映射：`u = x · W`，`v = y · H`。没有平移、旋转与镜像。

## 覆盖与状态

当前数据集包含 42 个子关卡底图，每单位恰好一张图：

- 291 条带位置条目中，277 条（95.2%）落在底图不透明区域；
- 18 张为 `calibrated`（已校准），同时给出中位误差与 P95；
- 其余 24 张为 `approximate`（近似位置）：18 张无带位置条目、5 张只有 1–2 条（样本不足）、
  980 的 P95 超出 calibrated 门槛；变换同样是解析恒等映射，不是拟合结果；
- 14 条坐标落在底图透明留白里（多为地下、隧道或地图边缘）。坐标本身没有错，界面用虚线外环标出。

没有底图的区域继续显示散点，并明确标注“坐标未校准”。

## 界面措辞的含义

| 文案 | 含义 |
| --- | --- |
| 已校准 | 中位误差 ≤ 0.5% 且 P95 ≤ 1% 图片对角线 |
| 近似位置 | 中位误差 ≤ 2% 图片对角线，或条目数不足以做统计验证 |
| 坐标未校准 | 没有可用底图，只显示同子关卡内的相对散点 |
| 位于底图留白区 | 取景框内没有绘制内容，不是定位失败 |

任何状态都不把点位表述成导航路线。数据集细节见[真实地图基底](/data/map)。
