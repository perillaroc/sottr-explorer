# 导出与分享

导出把当前快照写成 JSON 或 CSV，便于留档、比对或分享；收集计划页另可导出可打印清单，
概览页可生成面向社区的分享报告。

## 分享报告（概览页）

「分享报告」生成一个自包含的 `share.html`：总进度、区域进度与必收缺失清单，离线可读、
无外部资源，可直接发给别人。分享口径固定：

- 不含存档路径、用户名、输入摘要/哈希与快照时间；
- 写入**不存在的新目录**，不覆盖原存档或已有报告；成功后可用「打开导出目录」定位；
- **不包含地图缩略图**：D7 已决定暂不包含（2026-11-16），报告只给数字与清单。

写盘前后端会做路径样片段自检，命中即拒绝写出。

## 收集清单（收集计划页）

计划页只列**未收集**条目，并按 区域 → 子关卡 → 类别 聚合。点「导出清单」时：

- **HTML**：`plan.html`，自包含、无外部资源，可直接用浏览器打开或打印；每条前有复选框，
  便于边玩边勾。不写路径，适合发给别人。
- **CSV**：`plan.csv`，带 UTF-8 BOM，列包含区域、子关卡、类别、名称、内部 ID、口径（必收/可选/
  未闭合）、DLC、底图、文字下落、位置线索、获取方式与「已收取」空列。
- 导出内容就是**当前筛选**（仅必收/全部、区域、类别）；对话框会写出范围与条目数。
- 分享脱敏默认开启：不写输入文件名、快照时间与任何路径；关闭后才写入存档文件名与快照时间。

产物同样写入新目录，固定文件名为 `plan.html` / `plan.csv`；导出成功后可用「打开导出目录」
在系统文件管理器中定位（只接受本次运行刚写出的目录）。

## 导出格式

- **JSON**：`report.json` 是导出信封，包含快照身份、刷新状态、`input_digest` 与报告本体；
- **CSV**：`report.csv` 每行对应一项评估，列固定包含快照身份、观测、评估、证据等级、
  规则、定位精度等字段；候选名称以 JSON 数组逐字保留。

## 分享模式

开启分享脱敏后：

- 输入引用只保留文件名；
- 字符串中的路径样片段（盘符、UNC、`file://`、含分隔符的 `.dat` 引用）替换为文件名；
- 业务状态、证据、定位精度与 schema 不变。

脱敏是防御层，不等于内容一定适合公开；分享前仍应自行检查。

## 输出规则

- 目标必须是**不存在的新目录**，应用不会覆盖已有文件；
- 输出目录不得与输入文件或其所在目录重叠；
- 先写临时文件，全部成功后再提交；失败或取消会清理临时产物，不留下“完整报告”假象。

## 过期快照

如果当前输入已有旧快照、但最近一次刷新失败，导出会携带 `stale` 与刷新错误码；JSON 与 CSV
都有明确字段，不依赖文件名或截图传达过期。刷新失败不会把旧报告伪装成当前结果。
