# 使用指南

SOTTR Explorer 打开《古墓丽影：暗影》的本地存档，回答三个问题：**还差哪些收集品、
它们在哪、怎么拿**。所有判断都基于存档里出现了哪些 ID，不做估算；不确定的地方会
明确写“未知”。

## 阅读顺序

1. [快速开始](/guide/getting-started)：选择存档并完成第一次分析。
2. [界面导览](/guide/interface)：概览、全收集、收集计划、区域与收集、详情、诊断分别看什么。
3. [位置与地图](/guide/maps)：坐标是什么口径，为什么多数底图标“近似位置”。
4. [导出与分享](/guide/export)：JSON / CSV、分享脱敏与过期快照。
5. [常见问题](/guide/faq)：版本、存档安全、未知状态与地图覆盖。

::: tip 只读保证
应用只读取存档的稳定快照：读取前后哈希一致才生成报告，任何情况下都不会写回原文件。
:::

## 适用平台

仅支持 Windows Steam 版《古墓丽影：暗影》。存档默认位于
`文档\Shadow of the Tomb Raider\*.dat`，也可以在应用内手动选择。
