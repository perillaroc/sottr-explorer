# 常见问题

## 支持哪些版本？

仅支持 **Windows Steam 版**《古墓丽影：暗影》（含 Definitive Edition）。其它平台、
非 Steam 安装与修改过的存档不在支持范围内。

## 会修改我的存档吗？

不会。应用只读取稳定快照，读取前后哈希一致才生成报告；不写回、不修复、不改名、不删除。
导出也只写到你指定的新目录。

## 为什么有些条目显示“未知”？

“未知”是一个正式结论，不是失败：

- 存档结构可能不完整（例如异常 type28），此时会阻断缺席推断；
- 该条目可能没有可用的参考集合或计数证据；
- 可能属于未闭合的数据项（例如挑战古墓 ID 共用）。

应用不会用 0 或空清单冒充结论。具体原因见诊断页与[术语表](/reference/glossary)。

## 为什么地图上没有我的收集品？

底图覆盖不完整：42 个子关卡有底图，其余区域继续显示散点。即使有底图，少数点位也可能
落在透明留白区（地下、隧道或地图边缘）。这不代表坐标错误，详见[位置与地图](/guide/maps)。

## 为什么地图写“近似位置”？

只有中位误差 ≤ 0.5% 且 P95 ≤ 1% 图片对角线的单位才标“已校准”。其余单位使用同样的解析变换，
但条目数不足以做统计验证，因此标“近似位置”。

## 应用会联网吗？

不会。应用不加载网页、不上传存档、无账号与遥测。攻略链接只在你点击后交给系统浏览器打开。

## 数据从哪里来？

见图鉴、元数据与地图各自的数据页，以及[来源与许可](/data/sources)。第三方声明与许可全文
见[第三方声明](/legal/third-party)。

## 分析时游戏还开着可以吗？

建议先退出游戏。应用会读取稳定快照，但游戏并发写入可能导致刷新失败；失败时旧快照会被
明确标记为过期，而不是静默替换。

## 刷新后能看到这次多收了什么吗？

能。在同一存档上再次分析（或点刷新）后，概览页的「进度增量」会与上一次分析对比，
列出总进度、区域与具体新增条目；也可以在基线里选择本次会话中的其他槽位作对照。
历史只保留在本次会话内存中，关闭应用即清空；不写入磁盘，也不含存档路径。
不同存档（不同输入文件）、非战役上下文或物品表不完整时，界面会明确说明不可比，
不会把“看不到”当成“没有变化”。
