# 已知限制

按层列出当前做不到或不做的事；每条都说明用户会看到什么。产品内的诊断码与界面文案是正式
输出，本页只是汇总，不替代契约。

## 解析

| 限制 | 影响 | 界面/输出 |
| --- | --- | --- |
| 异常 type28 导致表不完整 | 不能推断“缺席” | `inventory_complete = false`，缺席推断阻断 |
| 挑战古墓 ID 共用（12 个名共享 9 个 ID） | 无法逐项判定 | 类别整体标 `null`，只按共用 ID 观察 |
| `profile.dat` 不参与战役语义 | 资料文件只做容器观察 | 单独标记，不进入进度 |
| 只覆盖 4 MiB 战役家族与已支持布局 | 未知布局不给结论 | `UNSUPPORTED_LAYOUT` / `UNSUPPORTED_CONTEXT` |

## 数据

| 限制 | 影响 |
| --- | --- |
| 任务目标（missions）语义未定 | 不展示为缺失 |
| 获取方式为类别规则 + 合集/子关卡指引 | 无坐标/无底图的必收条目有文字指引，但不是逐步路线，触发点未逐条核实 |
| 三个特殊区域没有存档区域计数器 | 单独成组，不参与主区域进度 |
| 参考集合当前要求“恰好一个” | 零个或多个时不猜选择规则，只留原始观测 |

## 地图

| 限制 | 影响 |
| --- | --- |
| 42/65 个子关卡有底图 | 其余区域显示散点，并可用合集/子关卡文字指引 |
| 291/470 条目录条目可上图 | 必收条目中 243/352 可上图；其余 109 条有文字指引 |
| 18 张已校准、24 张近似 | 24 张中 18 张无带位置条目、5 张样本不足、980 未过 P95 门槛；界面标“近似位置” |
| 14 条落在透明留白 | 虚线外环标出，不改写坐标 |
| 位置是关卡内相对位置 | 不是世界坐标，也不是导航路线 |
| 文字指引为合集/子关卡级 | 只说明归属与数量，不提供逐步路线 |

## 界面

- 详情弹窗是打开时的只读快照；主窗口刷新后不自动更新，需要重新打开；
- 存档监视只轮询当前选中的一个文件，不做目录递归扫描；检测到变化只提示刷新，
  不自动分析、不写入、不锁定文件；
- 更新/替换/占用/删除依赖文件身份、大小与最后写入时间；无法识别内容相同但
  元数据完全一致的改写（正常游戏保存会更新写入时间或文件身份）；
- 进度增量默认比较**当前存档在本次会话内**的两次分析；可显式选择其他槽位作对照，
  但不同输入文件不计算增量，只显示两侧摘要。历史仅存内存、关闭应用即清空；
  D5 已决定仅会话内，不提供显式保存到本地；
- 不同存档、非战役上下文或物品表不完整时不计算增量，界面明确说明原因；
- 分享报告为自包含 HTML（无外部资源），固定不含路径、用户名、输入摘要/哈希与快照时间；
  D7 已决定暂不包含地图缩略图；
- 地图不做跨子关卡拼图；
- 地图缩放到 4× 后标记不随缩放变大，避免遮挡。

## 平台

- 仅 Windows Steam 版；不支持其它平台、非 Steam 安装与修改过的存档；
- 存档发现与稳定快照读取依赖 Windows API。

## 研究与回归

- 公开 20 样本不随仓库分发，需按来源恢复；私有五文件只在开发工作站；
- 差分回归缺少夹具时跳过并记录覆盖缺口，不记为通过；
- 研究记录已发布公开整理版，私有路径以占位符替代；原始提取数据与研究包不随仓库或站点分发。
