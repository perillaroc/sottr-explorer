# 决策记录

这里只记录**已经定下、长期有效**的结论与理由；过程性方案与讨论留在开发工作区的
`doc/<日期>-<主题>/`，不进入站点。后续可以为每条拆成独立 ADR 页。

| 决策 | 结论 | 理由与约束 |
| --- | --- | --- |
| 平台范围 | 仅 Windows Steam 版 | 存档发现、快照与路径策略都按 Windows 实现；不维护多平台分支 |
| 只读 | 不提供修复、写回或改名 | 降低风险；所有结论可从原始字节复核 |
| 未知表达 | `null` + 原因，不用 0 或空清单 | 避免把“不知道”伪装成结论 |
| 证据分层 | observation / assessment / evidence_level 三者独立 | 防止“ID 出现”被当成“已收集” |
| 不做概率 | 不输出 confidence 小数或评分 | 没有校准依据的分数会误导 |
| 参考集合 | 当前要求“恰好一个” | 零个或多个时不猜选择规则 |
| 坐标空间 | 每单位独立归一化，无全局地图 | 游戏数据只提供单位内取景框，跨单位拼接没有依据 |
| 地图分发 | D4=A，底图随包分发 | 来源允许个人非商业使用；署名与许可随包 |
| 双数据集 | catalog 负责图鉴/位置，metadata 负责参考/计数 | 两者由 manifest 哈希与测试互相锁定，避免合并成一份难以演进的巨表 |
| 契约形态 | 全字段显式 + 禁止额外字段 | 变更可控；新增字段也算版本变更 |
| Python 参照 | v0.2 只作差分回归参照 | `candidate_*` 不得因改名升级为 `validated` / `verified_*` |
