# ADR-0007 坐标空间：每单位独立归一化

> 状态：已采纳（长期有效）。来源：[真实地图基底](/data/map)、[接口契约](/contracts)。

## 背景

游戏数据只提供**每个单位（子关卡）内**的取景框与归一化坐标；不同子关卡的 `[0,1]`
空间互不相通。跨单位拼接成世界地图没有数据依据。

## 选项

| 选项 | 说明 | 结果 |
| --- | --- | --- |
| 单位内归一化 | 每个子关卡独立取景框，坐标 `[0,1]`，y 向南 | **采纳** |
| 世界地图 / 跨子关卡拼图 | 需要全局坐标与关卡间变换，数据不提供 | 拒绝 |

## 决定

图鉴 `position` 是每单位独立的归一化空间：原点在底图取景框西北角，y 向下（向南）增大；
首版变换为纯比例映射 `u = x · W`、`v = y · H`。

## 后果

- 地图点位只表示**同一子关卡内的相对位置**，不是世界坐标，也不是导航路线。
- 详情页的“相对位置”与地图页共用同一套变换。
- 无底图单位只能给文字指引；P3-4 的 mesh 渲染也只做单位内底图，不拼世界地图。
