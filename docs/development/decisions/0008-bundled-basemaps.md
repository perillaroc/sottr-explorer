# ADR-0008 地图分发：底图随包分发（D4 = A）

> 状态：已采纳（2026-10-31）。来源：真实地图方案的 D4 授权策略、[真实地图基底](/data/map)、
> [许可](/legal/license)。

## 背景

社区投稿的底图能显著提升可读性，但素材版权归原权利人；分发方式必须在开始收集前定下。
真实地图方案列出三条路径，要求阶段 0 选一个。

## 选项

| 路径 | 做法 | 适用 |
| --- | --- | --- |
| A 随包分发 | 处理后的贴图打包进应用 | 确认拥有分发权时 |
| B 本地素材 | 应用不内置贴图，用户指向本地提取目录 | 授权不明时的默认 |
| C 不做底图 | 保持散点 | 授权无法确认且不接受本地素材 |

## 决定

2026-10-31 选定 **A**。依据：三份投稿（502127 / 502132 / 502133）作者均为 vi7ual，
站点 About 页声明素材供 “personal projects and non-commercial work”，本项目按非商业
用途分发；版权仍归原权利人。`image_root.kind = bundled`，`redistributable = allowed`。

## 后果

- 非商业分发；署名、来源与许可全文随包（`THIRD_PARTY_NOTICES.md`）。
- 每条底图必须带 `image_sha256`，由 `pnpm contract:images` 校验存在性、字节数、哈希与 WebP 尺寸。
- 商业用途需另行取得许可；MIT 不延伸至图片。
- 底图体积受打包体积约束：2026-11-19 P4-2 把长边 4096 的 17 张缩到 2048，42 张合计约 28 MB。
