# ADR-0006 参考集合：恰好一个才使用

> 状态：已采纳（长期有效）。来源：[架构总览](../architecture.md)、[已知限制](../limitations.md)。

## 背景

参考集合用于判断“参考中应当存在、当前未观察到”的条目。元数据里可能没有候选、
也可能有多个候选；此时选择哪一个都会改变结论，而没有依据。

## 选项

| 选项 | 说明 | 结果 |
| --- | --- | --- |
| 恰好一个才使用 | 只有一个参考集合时启用参考遗漏推断 | **采纳** |
| 零个或多个时猜规则 | 可能导致整组误报 | 拒绝 |

## 决定

当前规则为“恰好一个”（`MetadataBundle::primary_reference_set_id`）；零个或多个时不猜选择规则。

## 后果

- 非适用时只保留原始观测并给出诊断；参考遗漏推断与行动摘要关闭。
- 界面明确显示不可用原因，不展示“0 个遗漏”。
- 未来放宽规则属于契约变更，需要版本升级与测试更新。
