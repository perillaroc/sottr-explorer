# ADR-0010 契约形态：全字段显式 + 禁止额外字段

> 状态：已采纳（契约 1.0.0 冻结）。来源：[接口契约](/contracts)。

## 背景

宽松 schema 允许“多出来的字段”，看似兼容，实际会让不同版本的输出悄悄漂移：
消费方无法判断一个字段是新特性还是笔误。

## 选项

| 选项 | 说明 | 结果 |
| --- | --- | --- |
| 全字段显式 + `additionalProperties: false` | 契约外字段被拒绝，变更必须显式 | **采纳** |
| 允许额外字段 | 前端与 CLI 容易悄悄分叉 | 拒绝 |

## 决定

所有对象要求显式列出全部字段；契约外字段被拒绝。新增字段也属于版本变更，需要评审与升级
`schema_version`。

## 后果

- schema、Rust 类型与前端类型由同一份定义驱动（前端 `*.d.ts` 由 schema 生成，不手改）。
- JSON 解析拒绝 `NaN`、`Infinity` 与重复键；这一点 schema 表达不了，由解析落点在读取处强制。
- 适配旧 Python 输出必须通过显式适配器，原始报告可并存以便追溯差异。
- 64 位键一律用字符串往返，禁止经 JavaScript Number。
