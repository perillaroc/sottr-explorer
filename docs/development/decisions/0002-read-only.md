# ADR-0002 只读：不修复、不写回、不改名

> 状态：已采纳（长期有效）。来源：[安全模型](../security.md)、[架构总览](../architecture.md)。

## 背景

存档是玩家的唯一进度副本；任何写回、修复或改名都可能造成不可逆损失。工具的价值来自
“把原始字节解释清楚”，而不是替玩家修改文件。

## 选项

| 选项 | 说明 | 结果 |
| --- | --- | --- |
| 只读分析 | 读取稳定快照，只输出报告与导出文件 | **采纳** |
| 修复 / 写回 / 改名 | 可能破坏存档，且需要承担写入失败的责任 | 拒绝 |

## 决定

不提供修复、写回或改名；导出只写到用户指定的新目录。

## 后果

- 读取前后完整 SHA-256 一致才生成报告；前后不一致按 `INPUT_CHANGED` 处理。
- 导出先写 `.tmp`，全部成功后再逐一改名提交；失败或取消会清理临时文件与本次创建的目录。
- CSV 对 `=`、`+`、`-`、`@`、制表、回车及前导空白绕过加 `'` 转义。
- 所有结论都可以从原始字节复核，不依赖工具的中间状态。
