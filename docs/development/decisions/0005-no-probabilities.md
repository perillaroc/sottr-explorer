# ADR-0005 不做概率评分

> 状态：已采纳（长期有效）。来源：[架构总览](../architecture.md)、[接口契约](/contracts)。

## 背景

把“可能已收集”量化为 0.87 之类的分数看起来直观，但项目没有校准依据：既没有标注
数据集，也没有可复现的概率模型。没有校准的分数会被当成事实。

## 选项

| 选项 | 说明 | 结果 |
| --- | --- | --- |
| 不输出概率 | 只给离散的观察、评估与证据等级 | **采纳** |
| 输出 `confidence` 小数或评分 | 需要校准数据与持续评估，当前不具备 | 拒绝 |

## 决定

不输出 `confidence` 小数或任何评分；没有证据不给 `verified_*`。

## 后果

- 界面不显示置信度百分比；用“推定/已验证/未知”等离散措辞。
- 研究结论未验证前不进入产品图层（P3 各研究项均按此收口）。
- 以后若引入评分，必须先有校准方法与数据集，并按契约版本策略升级。
