# ADR-0003 未知表达：`null` + 原因，不用 0 或空清单

> 状态：已采纳（长期有效）。来源：[架构总览](../architecture.md)、[接口契约](/contracts)。

## 背景

数据缺失、物品表不完整、上下文不适用都很常见。把“不知道”写成 `0` 或空数组，会让
下游把未知当成结论——例如把“没有读到计数”显示成“没有收集品”。

## 选项

| 选项 | 说明 | 结果 |
| --- | --- | --- |
| `null` + 原因 | 可空字段为 `null`，并给出原因码或诊断 | **采纳** |
| `0` / 空清单 | 实现简单，但会把未知伪装成结论 | 拒绝 |

## 决定

可空字段用 `null` 表达，且必须带原因；合法零保留 `0`。

## 后果

- 契约里可空字段与“未知原因”成对出现；诊断码是正式输出。
- 界面显示“未知 / 暂不支持 / 不可用”，而不是 0。
- 物品表不完整或上下文不适用时，参考遗漏推断与行动摘要直接关闭，不猜测。
- 解析失败是输入级错误：不给部分报告充当完整结果。
