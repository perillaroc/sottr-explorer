# 数据与来源

产品只读消费三套版本化数据，原始素材与提取物留在仓库外。

| 数据集 | 内容 | 体积/规模 | 进包 |
| --- | --- | --- | --- |
| [全收集图鉴](/data/catalog) | 470 条收集品的区域、单位、位置与获取方式 | 单个 JSON | 是 |
| [收集品元数据](/data/metadata) | 866 个内部 ID、43 项区域计数、参考集合与攻略组 | 三个 JSON | 是 |
| [真实地图基底](/data/map) | 42 个子关卡底图与坐标变换 | JSON + 42 张 WebP（约 28 MB） | 是 |

生成链与所有权见[数据管线](/development/data-pipeline)；来源许可矩阵见[来源与许可](/data/sources)；
名称、区域、坐标与计数的提取、对账过程见[研究记录](/data/research/)。

## 共同规则

- 数据集版本化，加载器严格校验；缺项不是 0，未知不虚构；
- 元数据三个文件作为一组加载，引用必须可解析；
- 地图图片与数据集分开校验：`pnpm contract:images` 检查存在性、字节数、SHA-256 与 WebP 尺寸；
- 数据集不执行脚本、不自动联网更新。
