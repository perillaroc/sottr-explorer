## 稳定的东西

- 字段名、枚举值、单位与错误码都是契约的一部分，变更必须升级版本；
- 界面只依赖代码与枚举，不解析自然语言消息；
- 报告中的未知用 `null` + 原因表达，合法零保留 `0`。

契约的 JSON Schema 在仓库 `schemas/`，夹具在 `fixtures/contract/`；两者与 Rust 类型、
前端生成类型一起构成契约的四份载体。
